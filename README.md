# Anand Sampat - Personal Website

A clean, beautiful, modern personal website built from scratch.

## ✨ Features

- **Clean & Modern Design** - Beautiful, minimalist interface with excellent readability
- **Perfect Light/Dark Mode** - Smooth theme toggle with localStorage persistence
- **Fully Responsive** - Looks great on desktop, tablet, and mobile
- **Fast & Simple** - Pure HTML, CSS, and vanilla JavaScript (no frameworks)
- **Easy Navigation** - Smooth scrolling between sections
- **Writing Section** - Beautiful layout showcasing all blog posts and podcasts

## 🚀 How to Run

### Option 1: Open Directly in Browser (Easiest)

1. Navigate to the `new-site` folder
2. Double-click `index.html` to open it in your default browser

### Option 2: Using Python Server (Recommended)

```bash
cd /workspace/new-site
python3 -m http.server 8000
```

Then open your browser and go to: `http://localhost:8000`

### Option 3: Using VS Code Live Server

1. Install the "Live Server" extension in VS Code
2. Right-click on `index.html`
3. Select "Open with Live Server"

## 🔧 Customization

To make changes:

1. **Content**: Edit `index.html` - all text is clearly marked in semantic HTML
2. **Styling**: Edit `styles.css` - CSS variables at the top control colors
3. **Functionality**: Edit `script.js` - simple, commented JavaScript
